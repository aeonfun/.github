### How Aeon multiplies you

- **Plans the work.** Aeon plans the job as a task graph, where each task waits only for the ones it depends on.
- **Checks itself.** The model that finds a result never confirms it. A second model reproduces it in its own sandbox, and a fresh agent tries to break the proof. Only what holds ships.
- **Gets better.** Every run is scored one to five. A skill that fails three times gets repaired, and what it learns stays in memory.
- **Stays yours.** Runs in a private repo on your own GitHub, or locally on your own machine. You own every agent, every run, every output.

### Proof: open-source security

We gave our swarm one job: keep open-source code safe. It finds bugs before attackers do, writes the fix and follows it until merged. [See every fix](https://www.aeon.fun/security).
